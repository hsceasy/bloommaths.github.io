Viorosa Maths · Year 11 Mathematics Standard

Frequency tables and histograms

Key idea

Frequency counts observations. Histograms represent numerical intervals; for unequal widths use frequency density so area represents frequency.

Worked example 1

Values 1,1,2,3,3: frequencies 2,1,2.

Worked example 2

Class width 5 with frequency 20 → density 4.

Common mistake: Leaving gaps between adjacent continuous classes.
