Cosine rule

Non-right-angled Trigonometry course notes

Key concept

Use two sides and the included angle to find the third side, or three sides to find an angle.

c² = a² + b² − 2ab cos C

Worked example 1

Find c when a=5, b=8, C=60°.

c²=25+64−40=49; c=7.

Worked example 2

Find C when a=5, b=8, c=7.

cos C=(25+64−49)/80=0.5; C=60°.

Common mistake

Use the included angle.
