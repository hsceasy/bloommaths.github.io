Solving linear equations

Key idea

Apply the same operation to both sides to isolate the unknown.

Worked example 1

3x + 7 = 22 → 3x = 15 → x = 5.

Worked example 2

5x − 8 = 12 → 5x = 20 → x = 4.

Common mistake: Changing only one side.
