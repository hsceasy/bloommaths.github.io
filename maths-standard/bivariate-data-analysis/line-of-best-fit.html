Line of best fit

Bivariate Data Analysis course notes

Key concept

A fitted line predicts a response from an explanatory variable.

y = mx + c

Worked example 1

Predict y at x=4 using y=2x+3.

2×4+3=11.

Worked example 2

Interpret slope if x is hours and y is dollars.

Predicted y increases $2 per extra hour.

Common mistake

Include units.
