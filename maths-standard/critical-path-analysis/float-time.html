Float time

Critical Path Analysis course notes

Key concept

Total float is the delay allowed without delaying project completion.

Float = LF − ES − duration

Worked example 1

ES=3, LF=12, duration=5. Find float.

12−3−5=4.

Worked example 2

ES=2, LF=7, duration=5. Find float.

7−2−5=0; critical activity.

Common mistake

Float is not activity duration.
