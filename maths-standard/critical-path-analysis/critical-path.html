Critical path

Critical Path Analysis course notes

Key concept

The longest duration path determines minimum project completion time.

Critical path duration = sum of durations along path

Worked example 1

Parallel paths take 9 and 12 days. Find project duration.

12 days.

Worked example 2

If the 9-day path increases to 11 days, what happens?

Completion remains 12 days, assuming no other changes.

Common mistake

The critical path is not the shortest path.
